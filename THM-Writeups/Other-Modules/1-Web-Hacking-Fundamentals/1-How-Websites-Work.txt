How Websites Work:
	. When you visit a website, your browser makes a request to a web server
		. The goal of the request - Get needed information from the web server
		. This data is used to display information within your browser
	. What is a web server?
		. A web server is the remote computer which is handling your request
			. (Browser) Browser request -> Internet -> Browser Request (Web Server)
			. (Browser) Server Response <- Internet <- Server Response (Web Server)

	. The 2 Major Components of a Website:
		. The Front End (client side) - The way your browser renders a website
		. The Back End (server side) - A server that processes your request and returns a response
	. The Flow:
		. You send a request and the server sends a response containing the data you requested

HTML:
	. Websites are primarily built using:
		. HTML - Build a website and define its structure
		. CSS - Make a website look pretty
		. JavaScript - Implement complex features using user interactivity
	. HyperText Markup Language (HTML):
		. The language in which websites are written 
		. Elements - The building blocks of HTML
			. A website's HTML code consists of many elements
			. It tells the browser how to display content
			. Elements can be closed with an end tag:
				. Start Tag - <example>
				. End Tag - </example>
		. Example:
			  <!DOCTYPE html>
			. <html>
				<head>
					<title>Page Title</title>
				</head>
				<body>
					<h1>Large Heading</h1>
					<p>Paragraph</p>
				</body>
			  </html>
		. Core HTML Components:
			. <!DOCTYPE html> - Defines that the page is an HTML5 document
				. This tells the browser to use HTML5 to interpret the page
			. <html> - This is the root element of the HTML page
				. All other elements come after this element
			. <head> - Contains information about the page (page title)
			. <body> - Defines the HTML document's body
				. Only content within the body is displayed in the browser
		. Element Attributes:
			. HTML elements can each contain their own attributes
				. Examples: 
					. class - <p class="bold-text">
						. You can add multiple elements to a single class
					. src - <img src="img/cat.png">
						. Specify the location of an image file
					. id - <p id="info">
						. Unique to the element (unlike class)
			. Attributes are useful when working with HTML elements within JavaScript

JavaScript:
	. JavaScript (JS) is one of the most powerful programming languages in the world
		. JS allows a page to become interactive
	. HTML is used to create the structure while JS controls the functionality of the website
	. JS can dynamically update a web page in real time
	. How to include JS in your HTML documents:
		. Use a "" Tag Within HTML Document - JS code lives within the HTML doc between "<script>" tags
		. Point to a JS File Using "src" - <script src="/location/of/javascript_file.js"></script>
	. How to reference HTML elements within JS:
		. document.getElementById("testElement").innerHTML = "testElement text"
			. document.getElementById() - Reference your desired HTML element
			. .innerHTML = "" - Configure the text content of your chosen HTML element
	. HTML Element Events:
		. Example Events - onclick, onhover, oninput
		. <button onclick='document.getElementById("demo").innerHTML = "Button Clicked";'>Click Me!</button>
			. Once the button is clicked, the button text changes from "Click Me!" to "Button Clicked"
	. All in one HTML/JS example:
	. <!DOCTYPE html>
	 <html>
		 <head>
			 <title>TryHackMe Editor</title>
			
		 </head>
		 <body>
			 <button id='b1' onclick='document.getElementById("b1").innerHTML = "Changed..."'>Click to Change Text</button>
			 <div id="demo">Hi there!</div>
			 <p id="total">Var total: </p>
			 <script type="text/javascript">
				 var one = 4;
				 var two = 2;
				 document.getElementById("total").innerHTML = `Var total: ${one + two}`;
			 </script>
		 </body>
	 </html>
	
Sensitive Data Exposure:
	. Sensitive Data Exposure occurs when a website doesn't properly protect (or remove) sensitive clear-text information to the end-user
		. This is usually found in the websites source code
		. This info is accessible via right-clicking the page and selecting "view page source"
	. Once exposed, an attacker can leverage this information
		. Example: if temporary login credentials were found in the source code, they may still be valid
	. Common Data Exposure:
		. A lot of the time, this sensitive data consists of links/endpoints which never need to be known by the user

HTML Injection:
	. A vulnerability which occurs when unfiltered user input is displayed on the page
	. If the page fails to sanitize user input, an attacker can inject HTML code into the page
	. When a user has control of how their input is displayed, they can submit HTML/JS code
		. This allows the user to control the page's appearance and functionality
	. The rule of thumb when designing web applications:
		. Never trust user input
